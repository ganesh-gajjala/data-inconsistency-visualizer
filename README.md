## Data Inconsistency Visualizer

A lightweight Python script that utilizes `matplotlib` to generate a polished, publication-ready donut chart visualizing data inconsistency distributions. 

### Features
* **Custom Styling:** Optimized with *Times New Roman* typography and standard grayscale color schemes for academic or professional reports.
* **Donut Chart Conversion:** Automatically overlays a center patch to convert a traditional pie chart into an elegant donut chart.
* **Exploded Segments:** Highlights smaller, critical data anomalies using dynamic segment explosion.
* **Production Ready:** Pre-configured to export high-resolution (`300 DPI`) figures directly to PNG format.

### Requirements
Ensure you have Python installed along with the required visualization library:
```bash
pip install matplotlib
```

### Usage
Simply run the script to view the interactive plot and generate the output image file (`donut.png`):
```bash
python data_inconsistency_visualizer.py
```
